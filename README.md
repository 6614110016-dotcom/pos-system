# ระบบขายหน้าร้าน (POS) ด้วย Laravel Framework

ระบบขายหน้าร้านสำหรับร้านสะดวกซื้อ พัฒนาด้วย **Laravel 11 + Blade + Bootstrap 5 + MySQL**
ครอบคลุมตั้งแต่การเข้าสู่ระบบ จัดการสินค้าและสต็อก ขายหน้าร้าน รับชำระเงิน ออกใบเสร็จ ไปจนถึงรายงานสรุปยอดขาย

## โมดูลของระบบ

| # | โมดูล | ความสามารถ |
|---|-------|-----------|
| 1 | **ยืนยันตัวตน (Login)** | เข้าสู่ระบบด้วยอีเมล จำกัดการล็อกอินผิด 5 ครั้ง/นาที ตรวจสอบบัญชีที่ถูกระงับ เปลี่ยนรหัสผ่าน ออกจากระบบ |
| 2 | **สมาชิก (Member)** | เพิ่ม/แก้ไข/ลบ/ค้นหาสมาชิก ระดับสมาชิก (Silver/Gold/Platinum) ส่วนลดอัตโนมัติตามระดับ แต้มสะสม ประวัติการซื้อ |
| 3 | **พนักงาน (Employee)** | จัดการบัญชีพนักงาน กำหนดสิทธิ์ 3 ระดับ ระงับ/เปิดใช้งานบัญชี ดูยอดขายรายบุคคล |
| 4 | **สินค้า (Stock)** | จัดการสินค้าและหมวดหมู่ อัปโหลดรูป บาร์โค้ด รับสินค้าเข้าคลัง ปรับยอดสต็อก ประวัติการเคลื่อนไหวสต็อก แจ้งเตือนสินค้าใกล้หมด |
| 5 | **การขาย (Sale)** | หน้าจอ POS ยิงบาร์โค้ด ตะกร้าสินค้า ผูกสมาชิก ส่วนลดรายการ/ท้ายบิล เปิดบิล ยกเลิกบิลพร้อมคืนสต็อก |
| 6 | **จ่ายเงิน (Payment)** | รับชำระ 5 ช่องทาง (เงินสด/โอน/พร้อมเพย์/บัตร/e-Wallet) คำนวณเงินทอน แนบสลิป แยกชำระหลายช่องทาง ออกใบเสร็จ |
| 7 | **รายงาน (Report)** | รายงานยอดขายรายวัน สินค้าขายดี ยอดขายตามพนักงาน สมาชิก สต็อกคงเหลือ ช่องทางชำระเงิน + ส่งออก CSV |
| 8 | **อื่นๆ เพิ่มเติม** | แดชบอร์ดพร้อมกราฟ ตั้งค่าระบบ (ชื่อร้าน/VAT/แต้ม) และบันทึกการใช้งานระบบ (Audit Log) |

## ความต้องการของระบบ

| รายการ | เวอร์ชันขั้นต่ำ |
|--------|----------------|
| PHP | 8.2 ขึ้นไป (แนะนำ 8.3) |

## ขั้นตอนการติดตั้ง

### 1. ดาวน์โหลดโปรเจค

```bash
git clone https://github.com/6614110016-dotcom/pos-system.git
cd pos-system
```

### 2. ติดตั้ง Package

```bash
composer install
```

### 3. ตั้งค่าไฟล์ .env

```bash
cp .env.example .env        # Windows ใช้: copy .env.example .env
php artisan key:generate
```

แก้ไขค่าเชื่อมต่อฐานข้อมูลในไฟล์ `.env`

```env
DB_CONNECTION=mysql
DB_HOST=127.0.0.1
DB_PORT=3306
DB_DATABASE=pos_system
DB_USERNAME=root
DB_PASSWORD=
```

### 4. สร้างฐานข้อมูล

เข้า phpMyAdmin แล้วสร้างฐานข้อมูลชื่อ `pos_system` (Collation: `utf8mb4_unicode_ci`)
หรือใช้คำสั่ง

```bash
mysql -u root -e "CREATE DATABASE pos_system CHARACTER SET utf8mb4 COLLATE utf8mb4_unicode_ci;"
```

### 5. สร้างตารางและข้อมูลตัวอย่าง

```bash
php artisan migrate --seed
```

คำสั่งนี้จะสร้าง:

- ตารางทั้งหมด 13 ตาราง
- พนักงาน 4 บัญชี, หมวดหมู่ 6 หมวด, สินค้า 30 รายการ, สมาชิก 8 คน
- บิลขายย้อนหลัง 30 วัน เพื่อให้แดชบอร์ดและรายงานมีข้อมูลให้ดูทันที

### 6. เปิดใช้งาน

```bash
php artisan serve
```

เปิดเบราว์เซอร์ที่ <http://localhost:8000>

> **หมายเหตุ:** หากอัปโหลดรูปสินค้าไม่ได้บน Linux/macOS ให้สั่ง
> `chmod -R 775 storage bootstrap/cache public/uploads`

## โครงสร้างฐานข้อมูล

| ตาราง | หน้าที่ |
|-------|--------|
| `users` | พนักงาน + บัญชีเข้าสู่ระบบ |
| `members` | สมาชิกของร้าน แต้มสะสม ระดับสมาชิก |
| `categories` | หมวดหมู่สินค้า |
| `products` | สินค้า ราคาทุน ราคาขาย จำนวนคงเหลือ |
| `stock_movements` | ประวัติการเคลื่อนไหวสต็อกทุกครั้ง |
| `sales` | หัวบิลการขาย |
| `sale_items` | รายการสินค้าในแต่ละบิล |
| `payments` | การรับชำระเงินแต่ละครั้ง |
| `settings` | ค่าตั้งค่าระบบ |
| `activity_logs` | บันทึกการใช้งานระบบ |

**ความสัมพันธ์หลัก**

```
users (1) ──< (n) sales (1) ──< (n) sale_items (n) >── (1) products
                   │                                        │
members (1) ──<────┘                                        └──< (n) stock_movements
                   │
                   └──< (n) payments
categories (1) ──< (n) products
```

**สูตรการคำนวณเงิน**

```
subtotal        = Σ (ราคาขาย × จำนวน) − ส่วนลดรายการ
member_discount = subtotal × (%ส่วนลดตามระดับสมาชิก)
total           = subtotal − member_discount − ส่วนลดท้ายบิล
vat             = total − (total × 100 ÷ (100 + อัตรา VAT))    ← VAT รวมในราคาแล้ว
points_earned   = floor(total ÷ อัตราสะสมแต้ม)
```

## การทดสอบระบบ

```bash
php artisan test
```

ชุดทดสอบครอบคลุม

- การเข้าสู่ระบบ (ถูกต้อง / รหัสผ่านผิด / บัญชีถูกระงับ / ยังไม่ล็อกอิน)
- การเพิ่มสินค้าลงตะกร้าและการกันไม่ให้ขายเกินสต็อก
- การเปิดบิลแล้วตัดสต็อกถูกต้อง
- การรับชำระเงินและคำนวณเงินทอน
- การยกเลิกบิลแล้วคืนสต็อก
- การคำนวณส่วนลดสมาชิก VAT และแต้มสะสม
- การจำกัดสิทธิ์เข้าถึงเมนูตาม role
